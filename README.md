# 💸 Bill Splitter App

A simple terminal-based Python app that splits a total bill amount equally among a group of people.  
You can enter custom names and the amount will be calculated per person.

---

## 📌 Features

- ✅ Accepts any number of people
- ✅ Lets you enter custom names
- ✅ Validates user input (non-negative amount, valid numbers)
- ✅ Rounds each share to 2 decimal places
- ✅ Runs fully in terminal (CLI)

---

## 🚀 How to Run

If you have the `.py` file, you can run it using:
python bill_splitter.py

Or open the notebook version here:
